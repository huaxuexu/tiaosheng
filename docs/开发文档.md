# 会有时计数器 · 开发文档

> 中考体育 AI 视觉动作计数小程序（跳绳 / 垫排球）
> AppID：`wxdde4305611fe40f3`　·　项目名：`rope-timer`　·　基础库：`3.17.0`

---

## 1. 项目概述

「会有时计数器」是一款基于**微信小程序原生框架**的运动计数工具，核心能力是调用手机摄像头 + 端侧人体关键点检测，对**跳绳**与**垫排球**两类中考体育项目做实时、无接触的动作计数。

| 维度 | 说明 |
| --- | --- |
| 形态 | 微信小程序（原生，非 uni-app/Taro） |
| 计数方式 | VisionKit 原生 `body` 跟踪（23 点 2D 关键点），**不下载模型、不走网络** |
| 后端 | 无后端，全部数据本地存储（wx.Storage） |
| 付费 | 免费，会员等级为「本地累计成长」展示，无支付 |
| 设计语言 | 品牌橙 `#FF4E2A`，750rpx 视觉基准（原型按 375px，全部 ×2 转 rpx） |

### 历史架构变更（重要）
- **2026-07-27**：原 `subpackages/ai-count` 子包（MoveNet + tfjs 两套计数算法）已**整包移除**，见 `config/projects.js`。
- 现生产路径统一走 **VisionKit**（`index.js` 的 `initVK()` → `wx.createVKSession({ track: { body: { mode: 1 } } })`）。
- `workers/skipPose.js`（MoveNet + tfjs）、`package.json` 的 `@mediapipe/tasks-vision` 依赖、`utils/sensors.js`（加速度计辅助信号）均为**遗留/参考代码**，当前主链路未直接引用，保留供重新接入时参考。

## 4. 工具模块（utils/）

### 4.1 records.js —— 数据层核心
**记录结构**：`{ ts(开始时间戳), sport('rope'|'volleyball'), mode, count, durationSec, arch(0|1) }`

**两条铁律（务必遵守）**：
1. `getAll()` 永远返回原始读，**不做任何可见性过滤**（它是读-改-写路径，过滤会静默覆盖历史）。
2. 页面只读统计一律走 `getVisible()`；过滤只由 `getVisible()` 承担。

**登录门控**（2026-09-16 落地）：
- 登录 = 全量历史；未登录 = 仅「今日」。
- `arch` 字段区分档案(1)/缓冲(0)：未登录写入记为缓冲，超 `BUFFER_DAYS=7` 天清理；登录后缓冲整体升格为档案（`archiveBuffer()`）。
- 接口：`saveRecord / getAll / getVisible / aggregate(range,sport) / trend(range,n,sport) / total / totalBySport / bestCount / hasSport / streak / clear`。

### 4.2 auth.js —— 登录与资料
- `login()`：`wx.login()` 拿 code → **本地模拟** openid + 资料（无后端），并触发 `records.archiveBuffer()`。
- 接口：`isLogin / getProfile / saveProfile / logout / memberDays`。
- 接入真实后端：仅需把 `login()` 内「本地模拟」段替换为 `wx.request`。

### 4.3 member.js —— 会员成长
- `MEMBER_TIERS`：萌新→青铜→白银→黄金→王者（按累计训练总个数，阈值与成就页对齐）。
- `MEMBER_BENEFITS`：8 项权益，`reqLv` 解锁等级，对应 App 内真实能力。
- `computeMemberTier(totalCount)` / `buildBenefits(totalCount)`。

### 4.4 format.js / ui.js / voice.js
- `format`：`fmtTime(秒→MM:SS)`、`fmtDuration(秒→自然中文)`、`pad`。
- `ui`：`statusBarH()`（状态栏+6px）、`capsuleRpx()`（避让右上角胶囊）。
- `voice`：**女声倒计时**播放器。资源 `assets/voice/*.mp3`（edge-tts 生成→ffmpeg 转 16kbps 单声道）。关键实现：①相对路径引用代码包资源；②首次播放拷贝到 `USER_DATA_PATH` 兜底；③`obeyMuteSwitch=false` 静音也播；④每播新建 `InnerAudioContext` 并幂等回收；⑤`unlock()` 在用户手势内静音解锁音频后端。里程碑报数 `playMilestone(n)` 支持整十/整百拼接。

### 4.5 sensors.js（遗留）
加速度计/设备姿态辅助信号采集（规则 I~Y），作为 SkippingCounter 交叉验证的**参考实现**，当前主链路由 VisionKit 关键点直接 feed，未直接调用。

## 5. 计数算法（index 页核心）

### 5.1 数据流
```
摄像头 → VisionKit Session → updateAnchors(23点) → _onAnchors()
   → 取髋/肩/踝/膝/腕等关键点归一化坐标
   → counter.update({hip, hipX, ankle, knee, wrist, leg, shoulder}, Date.now())
   → { counter, status } 回写 setData
```

### 5.2 index.js 职责
- **权限流程**：隐私协议 → `scope.camera` 授权 → `initVK()`；未授权显示引导层（避免黑屏假死）。
- **WebGL 渲染**：`_initYUVShader` + `_renderCamera` 把相机帧渲染到 `#webgl` canvas（YUV→RGB）。
- **训练状态机**：`prep(统一5秒倒计时) → running → finished`。
- **分组训练（mode='group'）**：`准备 → 工作组 ⇄ 组间休息 → 结算`，时间一律**按墙钟推导**（`_phaseEndTs + ceil`），净训练时长由 `_groupBankWork()` 累计，避免 `setInterval` 误差累积（77 分钟长会话）。
- **语音策略**：5 秒准备倒数 / 每满 10 跳里程碑报数 / 结束前 10 秒秒倒数 / 定数最后 10 个倒数；倒数期间静音里程碑防叠音。
- **生命周期安全**：`onHide/onUnload` 必停 VK、定时器、常亮；`_pageAlive` 标记防止异步回调操作已销毁页面。
- **分享卡片**：`_drawShareCard()` 用 Canvas 2D 绘制（复刻原型版式），导出 PNG 后 `onShareAppMessage/TimeLine` 分享，或 `wx.showShareImageMenu` 弹原生面板。

### 5.3 SkippingCounter.js（跳绳计数）
高级抗抖动/抗丢帧/抗换人算法，核心 = **单特征（髋部归一化 Y）+ 自适应基线 + 迟滞 + 节奏锁相 + 防卡死**。

门禁层（多信号协同确认一次有效跳）：
- 主信号 `JUMP(髋)` 触发候选，需 ≥ `minVotes-1` 个辅助信号（ARM 腕 / FOOT 踝 / ACCEL 加速度 / ROPE 绳像素）在同步窗口内确认。
- `minVotes(1~4)` 默认 2；`sens(1~5)` 映射同步窗口（350ms→100ms）与迟滞带。

关键鲁棒性（可用 option 关闭以便回归）：
- **P0 节律验证门**（默认关）：中位数+多数一致判定稳定节奏。
- **P1 人体尺度归一化 (a) + 窗口极值基线 (b)**：阈值 ×尺度系数，距离无关。
- **P2 抗换人 / 检测中断全重置 / X 轴水平稳定门**（走动暂停计数）。
- **方案A 冷启动防误计**：`reset()` 不再让冷启动首帧误计 1 个。
- **方案B 晃动鲁棒性**：Y 基线漂移判定 moving → 重置跟踪态 + 恢复静默。
- **方案D 起跳上升幅度门 + 间隔门 + 会话建立门**：实现「0 延迟 + 0 误差」目标（fp01/fp02 误报=0）。首次计数需检测到节奏（约前 4s 延迟），此后每跳即时计数。

**关键 API**：`update(features, ts)`、`reset()`（清零计数）、`resetTrackingKeepCount()`（出框/丢跟踪时清跟踪态但**保留已计数量**）、`setSensitivity / setMinVotes / setMinPeriod / feedRope / setDebugMode`。

### 5.4 VolleyCounter.js（垫排球计数）
复用单方向周期检测器：双腕平均竖向位置（含肘部冗余），`wrist`/`elbow` 两通道各自「抬手→回落」触发，≥ `minVotes` 通道在 `voteWindow` 内协同即计 1 次。仍属「真机调参阶段」，最佳阈值用调试面板校准。

### 登录门控统一原则
未登录时只回答「今天练了多少」；趋势、环比、挑战进度、成就、历史明细等**时间纵深**一律锁定，并在 UI 明示规则（如「暂存 7 天」），不做隐藏式门槛。`records.isLoggedIn()` 是各页门控唯一判据。

## 10. 已知注意事项（来自代码注释）

- **`reset()` vs `resetTrackingKeepCount()`**：出框/丢跟踪用后者（保留成绩）；全重置用前者（清零）。误用会导致中途出框成绩归零。
- **时基一致性**：`counter.update()` 必须传真实 `Date.now()`，否则退化为「帧序×33ms」假时基 → 真机快跳被吃（漏计）。
- **VisionKit 关节映射**：23 点索引官方仅图示无表，`BODY_IDX` 已注释校准（髋=11/12）。换设备后用调试浮层（`index.js` toggleDebug）核对。
- **页面存活**：所有 `onHide/onUnload` 必须释放 VK Session / WebGL / 定时器，否则后台累积资源 → Android native 崩溃。
- **分享卡片分辨率**：`canvasToTempFilePath` 的 `destWidth/destHeight` 必须按设备像素（画布物理分辨率），否则真机字发虚。
